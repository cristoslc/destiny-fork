# User Experience

## UX Principles

- **No sign-up needed** — the app works immediately after installation
- **Identity-less** — no name, email, or phone number required
- **End-to-end encrypted by default** — files are encrypted before leaving the device
- **Short human-memorable codes** — codes like "7-cactus-suitcase" are easy to share verbally

## User Journeys

### Send a File
1. Open Destiny
2. Tap "Send"
3. Select a file from the device
4. Share the generated code with the recipient (out-of-band)
5. Wait for the recipient to connect
6. File transfers automatically

### Receive a File
1. Open Destiny
2. Tap "Receive"
3. Enter the code shared by the sender
4. Wait for the connection
5. File is saved to the device

## UI Conventions

- Material Design with custom theming
- Montserrat and Roboto font families
- Dark and light mode support
- Progress indicators during transfers
- Drag-and-drop file selection on desktop platforms

## Accessibility

- Screen reader support via standard Flutter accessibility APIs
- Sufficient color contrast in both light and dark themes
- Touch-friendly target sizes on mobile
