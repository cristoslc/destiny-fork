# docs/musings/

Pre-artifact thought capture. Raw ideas, half-formed concepts, exploratory notes, and fragments that may later coalesce into ADRs, specs, spikes, or other artifacts.

Files here follow no fixed format — they are freeform markdown. This directory signals content maturity: musings are less structured than plans, which are less structured than ADRs.

See `docs/musings/AGENTS.md` for the Muse ritual protocol.
